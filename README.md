# 📸 Passbild Editor (Python)

Ein einfacher Passbild-Editor mit:

- Zoom (in/out)
- Bild verschieben (Pan)
- Rotation ±90°
- Fixes Passbild-Overlay (Ratio 1.3)
- Export als Crop-Datei

---

## Requirements
- python3
- python-tk
- uv

## 🚀 Installation (mit uv)

```bash
uv run --script passbild.py
```
